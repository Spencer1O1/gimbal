## Locked Decisions

- **Production language:** Rust
- **Proof language:** Lean 4
- **Core semantics:** free bicartesian closed category generated by a signature
- **Equality:** saturated focusing
- **Equality requirement:** machine-checked termination, soundness, and completeness
- **Metatheory requirement:** machine-checked syntactic category and free-BCC theorem
- **Implementation verification:** extraction, verified translation, or machine-checked refinement
- **Intended initial refinement tool:** Aeneas
- **IR ownership:** immutable `Arc` trees
- **Object representation:** opaque handle around exhaustive enum
- **Unchecked representation:** resolved `Term`
- **Checked representation:** separate typed `Morphism`
- **Signature construction:** builder to immutable signature
- **Identifiers:** typed IDs
- **Signature identity:** exact context identity plus canonical fingerprint
- **Aliases:** outside Phase 0
- **Simplification:** sound but not equality-complete
- **Runtime values:** object-tagged dynamic values
- **Abstract models:** categorical, independent of Rust
- **Runtime model faults:** explicit trusted faults
- **Parser, source spans, serialization, and interning:** deferred unless needed

## Core Rust Representations

### Typed IDs

```rust
pub struct BaseId(u32);
pub struct GeneratorId(u32);
```

### Signature identity

```rust
pub struct SignatureContextId(/* private */);
pub struct SignatureFingerprint(/* private */);
```

### Unresolved signature objects

```rust
pub enum ObjectExpr {
    Base(Name),
    Unit,
    Never,
    Product(Box<ObjectExpr>, Box<ObjectExpr>),
    Coproduct(Box<ObjectExpr>, Box<ObjectExpr>),
    Exponential(Box<ObjectExpr>, Box<ObjectExpr>),
}
```

### Resolved objects

```rust
pub struct Object(Arc<ObjectData>);

struct ObjectData {
    signature: SignatureContextId,
    node: ObjectNode,
}

enum ObjectNode {
    Base(BaseId),
    Unit,
    Never,
    Product(Object, Object),
    Coproduct(Object, Object),
    Exponential(Object, Object),
}
```

### Terms

```rust
pub struct Term(Arc<TermData>);

struct TermData {
    signature: SignatureContextId,
    node: TermNode,
}
```

### Morphisms

```rust
pub struct Morphism(Arc<MorphismData>);

struct MorphismData {
    signature: SignatureContextId,
    source: Object,
    target: Object,
    node: MorphismNode,
}
```

Only trusted code creates `Morphism`.

## Signature Builder

The builder must:

1. Validate names.
2. Reject duplicate bases.
3. Assign deterministic base IDs.
4. Resolve generator object expressions.
5. Reject undeclared bases.
6. Reject duplicate generators.
7. Assign deterministic generator IDs.
8. Build immutable declarations.
9. Compute canonical fingerprint.
10. Create a fresh context identity.

Canonical fingerprints must not depend on:

- Hash-map iteration order
- Memory addresses
- Process-local IDs
- Platform-specific formatting

---

## Term Boundary

Public term constructors enforce:

- Structural validity
- Signature-context consistency
- Valid typed IDs

They do not enforce categorical typing.

The checker must remain able to diagnose:

- Invalid composition
- Pair source mismatch
- Case target mismatch
- Invalid curry source

---

## Kernel Checking

Primary operation:

```rust
pub fn check(
    signature: &Signature,
    term: &Term,
) -> Result<Morphism, CheckError>;
```

The successful result is trusted typed IR.

Ordinary downstream operations should not repeat source-level checking.

Internal impossible states produce `KernelFault`.

---

## Formatting

Formatting must support:

- Objects
- Terms
- Checked morphisms
- Typed arrows
- Simplified morphisms

It must be:

- Deterministic
- Context checked
- Independent of pointer identity
- Explicit about composition association
- Clear about `⟶` versus `⇒`

## Simplification

Primary operation:

```rust
pub fn simplify(
    morphism: &Morphism,
) -> Result<Morphism, KernelFault>;
```

Every rewrite must preserve:

- Signature
- Source
- Target
- Definitional meaning

Simplification does not define equality.

## Equality API

```rust
pub fn definitionally_equal(
    left: &Morphism,
    right: &Morphism,
) -> Result<bool, EqualityError>;
```

The operation rejects mismatched:

- Signature contexts
- Sources
- Targets

For compatible arrows, it invokes the verified procedure.

## Abstract Model Interface in Lean

The Lean semantics must define a target bicartesian closed category independently of runtime execution.

A model interpretation assigns:

- Each base generator to a target object
- Each morphism generator to a target morphism

Interpretation of all core morphisms is derived.

## Runtime Interpreter

The Rust interpreter is one executable model adapter.

Conceptually:

```rust
pub struct Value {
    object: Object,
    repr: Arc<ValueRepr>,
}
```

Only base payloads use type erasure.

The interpreter owns categorical runtime structure.

The runtime model supplies generator implementations.

Every generator call validates input and output object tags.
