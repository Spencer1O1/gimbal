**Status:** Long-term staged plan  
**Purpose:** Reach the full language without compromising the trusted categorical foundation.

---

## Phase 0A: Structural Semantic Kernel

Implement the explicit total and pure bicartesian-closed syntax in Rust.

### Includes

- Signature builder
- Resolved immutable signatures
- Typed base and generator IDs
- Structural objects
- Explicit potentially ill-typed terms
- Checked morphisms
- Exact typing rules
- Sound simplification
- Runtime model adapter
- Closed-program interpretation
- Deterministic formatting
- Clear diagnostics

### Object forms

```text
Base(id)
Unit
Never
A × B
A + B
A ⇒ B
```

### Morphism constructors

```text
id
composition
discard
absurd
first
second
pair
left
right
case
curry
eval
signature generators
```

### Completion signal

The Rust kernel can build, check, inspect, simplify, and interpret explicit pure categorical programs.

Phase 0 is not complete yet.

## Phase 2: Strictly Positive Algebraic Data

Introduce inductive data through initial algebras of approved functors.

### Includes

- Polynomial functors
- Functor action
- Strict positivity checking
- Fixed-point objects
- Initial algebras
- Catamorphisms
- Structural recursion
- Paramorphisms where justified
- Fusion
- Termination-safe recursion

### Canonical examples

```text
NatF[X] = Unit + X
Nat     = μX. NatF[X]
```

```text
ListF[A, X] = Unit + A × X
List[A]     = μX. ListF[A, X]
```

### Explicit distinctions

The language must distinguish:

- Initial algebra from mere fixed-point isomorphism
- Iso-recursive from equi-recursive behavior
- Induction from unrestricted recursion
- Coinduction from ordinary recursion
